A program that writes one haiku about debugging — three lines in the 5-7-5 syllable shape, seventeen syllables in all — to `/output/entry.txt`:

> Three a.m., breakpoint
> the log scrolls on; nothing fails
> except my own code

## Run it

```sh
node main.ts
```

Set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` is written (default `/output`). The output is exactly the three haiku lines, with no trailing newline.
